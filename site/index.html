Daily work receipt

Your whole work day, printed as a receipt.

A tiny macOS desktop widget that shows everything you got done that day: your AI coding sessions, the sites and docs you worked in, the commits you shipped. Grouped and copy-paste ready for a standup, timesheet, or task sheet. It rebuilds itself from files already on your Mac.

Install View source

Local-first, no API keys, no telemetry. EOD reads local files and writes a receipt to its own cache/ folder. One optional exception is described under requirements.

Specimen

Frameless, transparent, and it prints down.

Only the cream paper shows on your wallpaper. Drag it by the masthead; it floats over full-screen apps, prints down when opened and rolls up when closed.

Sample data. EOD builds these from your own activity, on your Mac.

Where it pulls from

Five local sources, one receipt.

Claude Code
+ Codex
Your coding sessions, per project, under WORK. Read from their local JSONL transcripts.
Git
Shipped commits and PRs. Read from repos in your work folders.
Documents
Decks, docs, sheets and PDFs you created or edited. Read from your work folders.
Browsing
The sites you spent time on, under WEB. Read from Chrome, Brave or Safari history.
Apps
SCREEN TIME. Read from local app-usage.

Each line is the work done: the AI-generated session title from Claude Code or Codex, a clean one-liner. No raw prompts.

Features

Built for the ten minutes before standup.

  • Auto-built daily from your local activity. Rolls over at midnight, refreshes through the day.
  • Multi-source. Claude Code and Codex sessions, git commits, documents, browsing and screen time on one receipt.
  • Daily receipt and weekly recap, one keystroke from the menu bar.
  • Copy all, or copy a single project, straight to the clipboard.
  • Edit inline. Fix a line, add one, or delete one before you copy. On the weekly recap your hand-edits stick and survive a re-summarize, unless you force one.
  • Browse previous days with the arrows, for back-filling a sheet.
  • Hide private projects via an exclude.txt file, for NDA or job-hunt work.

Requirements & permissions

Two required pieces, both free.

Both are most likely already on your Mac. The rest just determines what shows up on the receipt.

Hammerspoon required
The free automation app that hosts and draws the widget. Grant Accessibility in System Settings, Privacy & Security, Accessibility. Needed for dragging and the hotkey.
python3 required
Runs extract.py, the parser behind the receipt. Check with python3 --version. No permission needed. Looked up in /opt/homebrew/bin, /usr/local/bin, /usr/bin.
Claude Code / Codex
EOD reads their local JSONL transcripts for the WORK section. Use at least one. No permission needed. It only reads files already on your Mac.
Browser history
Powers the WEB section. Chrome and Brave are automatic. Safari history may need Full Disk Access for the Hammerspoon process.

The one exception to local-only is the optional AI-polish step. If your claude CLI is logged in, EOD asks it to rewrite the day into crisper, manager-ready bullets. That goes through your existing CLI login, not an API key. Missing CLI? It silently falls back to fully-offline cleanup.

Install

About three minutes.

  1. Don't already use Hammerspoon? Drop EOD straight into its config.

    mkdir -p ~/.hammerspoon && cp -R ./* ~/.hammerspoon/

  2. Open Hammerspoon, then Reload Config (⌥⌃⌘R). The receipt prints down in the top-right.

Already have an init.lua? Don't overwrite it. See INSTALL.md for the two lines to add instead.

How it works

Two files.

  • extract.py parses every Claude Code and Codex *.jsonl transcript for the target day, takes each session's AI title, de-dupes per project, folds in git commits, documents, browser history and app usage, filters noise, and writes a self-contained receipt HTML to cache/.
  • eod.lua is a Hammerspoon module that renders that HTML in a frameless hs.webview, runs the engine on a timer, and handles copy, navigation, dragging and animation.
